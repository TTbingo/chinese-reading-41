第 0 编

底层规律

五条规律，是全书的认知底座：先想清楚阅读题到底在考什么，再谈怎么答。

一切题只考三样东西

写了什么（内容）、怎么写的（手法）、为什么写（主旨情感）。任何一道阅读题，答案都落在这三格里。对照：记叙文的「法→果→点→心」、人物题的「人形点心」、说明文的「方作特」，是同一个骨架换了三次皮。

一切答案都是三段

先定位（哪句、哪段），再分析（用了什么、写出什么），最后归结（表现什么、表达什么）。缺一段就扣分。对照：41 个考点的答题模板，全部是这个三段结构的变体。

位置决定结构作用

开头、中间、结尾的结构作用由位置直接决定，与写了什么无关；内容作用才看写作对象。对照：段落作用、句段作用、开头结尾作用三个题型，结构项几乎完全相同。

文体决定答点

同一个「作用题」，记叙文答环境·情节·人物，说明文答说明对象特征，议论文答论证。先判文体，再选答点。对照：「关键句段作用」在记叙文与说明文各有一份，答点完全不同。

口诀是检索钩子，不是答案

22 条口诀对应 22 个固定的动作序列。考场上用它保证不漏点，但具体内容仍要从文章里取。对照：所有口诀后面都要接「……」，横线里填的才是文章里的话。本页每条口诀都可以点开：逐字拆解＋对应步骤＋为什么是它。

总纲

总体思维策略与方法方针

认知立住之后，是动作。怎么审题、怎么读文、怎么定位、怎么落笔、怎么分时间，都在这一节。

一六大答题思维方针

六条按先后顺序排开，是一条流水线：先审题，再读文，再定位，再落笔，最后复查。

认真审题，切忌粗心静下心来，按由易到难、由浅入深的思路作答；看清每一个字、词、句甚至标点，明确题目要求与提问要点。题目要求在正确句子后打「√」，就不必多此一举在错误句后打「×」。
熟读全文，整体把握先通读一遍文章，有初步了解再做题；读第二遍前可先浏览题目，因为问题中往往隐含文章的主要观点、中心意思、写作思路和行文线索。反复阅读、强化感知，切忌草草了事。
确定区域，深入思考先判断题目涉及文中哪些段落或语句，锁定「答题区域」后深入思考该段每句的意思，理清段落关系与行文思路；答题时无需再从头搜寻，省下时间。
巧妙借助「原话」答题要求用原文回答的，直接用原话；未指定时也尽量借用原文；要求「用自己的话回答」时，要先理解原话的隐含信息和深层含义，再重新组织语言。
选择适当方法，言之有理开放性答案要能自圆其说、言之有据；语言简洁明了，避免重复啰嗦。
合理控制时间，先易后难先浏览全文了解概貌，记住要点和关键的人名、地点、定义、数字，可用铅笔做记号便于查找；难题果断暂时放弃，做完后再回头补答；最后带着答案回归原文复查。

二语境分析「四不离」

理解字、词、句的通用法则。范围由小到大，外面那一层，永远是里面那一层的根据。

字不离词理解某个字的意思，必须把它放到词语中去考察。
词不离句理解词语在上下文中的含义和作用，要根据句子本身的语言环境去推断。
句不离段分析句子不能离开具体语段和环境，要知道它在全文中的位置。
段不离文理解段落不能偏离文章中心和主要意思，否则会产生偏差。

三四种按题型选用的解题方法

四种方法不是四选一，而是看题目问什么，各取所需。

上下联系把问题放回上下文中去思考，看它前后的句子在说什么。用于理解词义、理解含义深刻的句子、找近反义词。
换位思考与作者角色互换，站在作者的立场上去回答。用于问答题、体会作者思想感情。
联系生活跳出文本，联系学过的课文、知识积累和生活经验。用于谈感想体会、理解含义深刻的句子。
立足中心一切问题都从文章中心出发去思考，答案才有落脚点。任何题型都要回到中心。

四选择题三法与主观题一法

先分流：选择题求稳，主观题求准。

直选法答案一目了然时，直接选出。选择题的第一选择。
排除法排除不合要求的选项，让正确答案自己显现。选项拿不准时用。
类推法合理推断排除选项，或由已知推断未知。几个选项都吃不准时用。
回文找答案法问答题、概括段落大意类题目最有效的方法：在原文中找答案，再按题目要求加工——摘取词语、压缩主干、抽取要点或重新组织。
第 0’ 编​

读前策略

五编考点管「怎么答题目」，这一编管「怎么读文章」。做题之前先读通，是一切的起点。

预测与推想读前策略

主动思考、大胆推测，不是胡乱猜测，而是基于文本线索的科学推理。它把静态的阅读变成一次动态探索。

方法：捉迷藏读书法
  1. 第一步·读前预测：看到文章的标题，就像看到藏宝图的起点，大胆猜一猜：这篇文章可能会讲一个什么样的故事？会介绍哪方面的知识？
  2. 第二步·读中推想：读完开头先停下来，用一张小纸片遮住后面的内容，问自己「接下来故事会怎么发展」；读到关键段落，先思考「作者会得出什么结论」。
  3. 第三步·读后验证：读完全文，把自己的预测与文章实际内容对比。想一想：我猜对了吗？哪些地方猜对了，哪些不一样？为什么会不一样？
小林多喜二读列宁著作时，常用纸把后面列宁的论述遮住，自己先深入思考。别人问他，他答：「我先想想，然后再去看列宁的批判。」发现自己的想法和列宁不完全一样时他反而更高兴，因为「这样一来，我更理解列宁的观点了」。
高频考法根据文章标题，预测文章可能讲述的主要内容。
根据故事的开头或发展，推测故事可能的结局。
根据文中的某个细节或伏笔，推断人物接下来可能会有什么样的行为或心理活动。

童话世界读前策略

童话用奇特的想象、鲜明的人物形象构建神奇世界。读童话不只要欣赏情节，更要读懂背后关于真、善、美的道理。

方法：三步走
  1. 第一步：读懂故事讲了什么。
  2. 第二步：分析人物形象如何。
  3. 第三步：领悟故事蕴含的道理。
四个分析要点：①分析人物形象——形象特征 + 具体表现；②概括主要内容——六要素梳理法；③理解故事寓意——提炼启示 + 结合文本 + 联系生活；④赏析题目作用——字面意思 + 深层含义 + 作用赏析。
高频考法请用简洁的语言概括这个故事的主要内容。
你认为文中的 ×× 是一个怎样的角色？请结合具体事例进行评价。
读完这个童话故事，你明白了什么道理？
你觉得这篇文章的题目好在哪里？请分析一下。

寓言故事读前策略

寓言通过短小精悍、带有比喻性质的故事寄托道理。最关键的能力是「透过现象看本质」——不满足于知道「发生了什么」，要挖出背后的人生哲理。

方法：三环节
  1. 理解故事内容：用六要素梳理法或关键词串联法，快速准确把握寓言讲了一个什么故事。这是理解寓意的基础。
  2. 挖掘深层寓意：重点分析故事的结局和关键角色的言行，思考作者想告诉我们什么道理。常用公式「这个故事告诉我们……（道理）」。
  3. 联系实际拓展：把道理与自己的生活、学习或观察到的社会现象联系起来，用自己的话阐述理解。
寓言阅读的精髓在于「由事悟理」。一篇寓言的价值不在故事多曲折，而在其中蕴含的、能跨越时空的智慧。
高频考法这则寓言（或文中画线的句子）告诉我们一个什么道理？
你如何评价故事中 ××（某个角色）的行为？
结合你的生活实际，谈谈这则寓言给了你什么样的启示。

写人记事读前策略

写人记事类文章以记叙人物的经历和事件的过程为主要内容，是小学阶段的重点，也是难点。读这类文章要牢牢抓住「人」和「事」两条主线：「事」是「人」的载体，「人」是「事」的核心。只有理清事件的脉络，才能读懂人物的形象和文章的主旨。

方法：两条主线 · 四步读法
  1. 第一步·理清事件脉络：用六要素梳理法，依次找出时间、地点、人物、起因、经过、结果，再用简洁通顺的语言串成一段完整的话。事理不清，后面的人物和主旨都站不住。
  2. 第二步·分析人物形象：走「形象特征 + 具体表现」。先用准确的词语概括人物的性格特点，再从语言、动作、神态、心理等细节描写中找出能支撑这个判断的具体事例，不能只贴标签。
  3. 第三步·把握文章主旨：走「提炼启示 + 结合文本 + 联系生活」。先说出文章想告诉我们什么道理，再回到文中找依据，最后落到自己的实际谈感悟。
  4. 第四步·看清记叙顺序：判断文章是否用了非顺叙。倒叙常用来设置悬念、突出中心；插叙和补叙用来补充相关内容，使人物形象更丰满、故事情节更完整。
「事」是「人」的载体，「人」是「事」的核心。这四步分别落在第一编的考点 03（概括内容）、14（人物形象）、05（把握主旨）、06（记叙顺序）上，读完就能直接去翻对应那张卡。
高频考法请概括这篇文章（或某一段）的主要内容。
结合文章内容，说说文中的 ×× 是一个怎样的人。
读完这篇文章，你有什么感悟或启示？
本文采用了哪一种记叙顺序？这样写有什么好处？

写景状物读前策略

写景状物类文章用生动形象的语言描绘自然风光或物品特征，字里行间融入了作者浓厚的情感。阅读的重点是品味语言、分析写法、体会情感，最高境界是「入情入境」——通过对语言和写法的细致分析，真正走进作者描绘的画面。

方法：入情入境 · 四步读法
  1. 第一步·赏析修辞手法：先识别比喻、拟人、排比、对比、反问、设问，再走「修辞手法 + 作用赏析」。如「这句话运用了比喻，生动形象地写出了（景物）……的特点，表达了作者……的情感」。
  2. 第二步·分析表现手法：识别动静结合、点面结合、先抑后扬等，走「指出手法 + 结合内容 + 作用分析」。先说用了什么手法，再引文中的具体内容，最后说这样写好在哪里。
  3. 第三步·理解景物描写的作用：从环境特点、渲染氛围、烘托情感、推动情节、深化主题中，按文章的实际情况选几点分析，不要五点全抄。
  4. 第四步·品味语言特色：赏析文中用得精妙的动词、形容词、数量词，走「词句意思 + 表达效果」两步——先解释这个词在句中的意思，再说它好在哪里。
前三步答的是「怎么写的」「为什么写」，第四步答的是「哪个词写得好」。赏析句子的题走前三步，赏析加点词的题走第四步，两条路不要混着答。
高频考法请赏析文中画线句子的表达效果。
文中运用了哪种（或哪些）表现手法？这样写有什么好处？
请结合文章内容，分析文中的景物描写起到了什么作用。
你认为文中加点的「××」字好在哪里？请简要分析。

叙事性作品编者归纳

小说和名著片段是写人记事的加强版：人物更多，情节更曲折，还多了一层「环境」。读这类文本要抓住人物、情节、环境三要素，再往上归结出主题。

方法：三要素 + 主题读法
  1. 第一步·理清情节：按「起因—发展—高潮—结局」把故事分成四截，先把「发生了什么」说清楚；遇到倒叙、插叙，先还原成顺叙再梳理。
  2. 第二步·抓住人物：从肖像、语言、动作、心理的正面描写中概括性格，再从他人的言行与评价中补充侧面描写。人物往往不是一成不变的，注意情节前后的变化。
  3. 第三步·看清环境：分清自然环境与社会环境。自然环境交代时令地点、渲染气氛、烘托心情；社会环境交代时代背景、暗示人物命运。
  4. 第四步·归结主题：把「人物命运 + 情节走向 + 环境描写」合到一起，回答「作者通过这个故事想说什么」，开放题走「提炼启示 + 结合文本 + 联系生活」。
叙事性作品的答法与第一编写人记事同源：概括内容用六要素（考点 03），分析人物用「形象特征 + 具体表现」（考点 14），环境描写的作用看考点 08。差别只在文本更长、人物更多。
高频考法请用简洁的语言概括本文（或某一段）的主要内容。
结合具体情节，分析 ×× 这一人物形象。
文中的环境描写有什么作用？
读完这篇文章，你受到了什么启发？请结合生活实际谈谈。

科普说明文读前策略

科普说明文旨在介绍科学知识、解释自然现象或阐述事物原理，语言科学、准确、严谨。阅读的重点是获取有效信息、理解说明方法、体会语言的准确性。读说明文像和一位严谨的老师对话，要抓住「介绍了什么」「用什么方法介绍」「用词准不准」三条线。

方法：四问读法
  1. 第一问·写了什么：先确定说明对象及其特征。看标题、抓开头的总起句与结尾的总结句、抓反复出现的词语，分清是事物说明文还是事理说明文。
  2. 第二问·怎么写的：识别说明方法——举例子、列数字、作比较、打比方、下定义、作诠释、列图表、摹状貌；再走「运用 ×× 说明方法 + 具体说明内容 + 使说明更……」：列数字→准确具体，打比方→生动形象，作比较→突出鲜明，下定义→科学严谨，列图表→简明直观。
  3. 第三问·按什么顺序写：时间顺序（按事物发展的过程）、空间顺序（按方位或位置）、逻辑顺序（从现象到本质、从原因到结果），好处是条理清晰、符合人们的认知规律。
  4. 第四问·用词能不能删：重点分析「大约」「可能」「一些」「主要」这类限制性词语，走「明确表态（不能删去）+ 正反解释（原意是什么，删去后意思有何变化）+ 说明效果（体现说明文语言的科学性、准确性）」三步。

非连续性文本读前策略

图表、海报、说明书、时刻表——信息不以连贯段落出现，而由图、表、数据、短文组成。考的是快速定位、准确筛选、有效整合的能力。

方法：五步寻宝
  1. 第一步·明确阅读目的：先仔细读题目，弄清楚要求查找什么信息。带着问题去阅读，目标才明确。
  2. 第二步·浏览整体结构：快速扫视，看标题、包含哪几个部分、有没有图例或备注，对信息分布有大致了解。
  3. 第三步·定位关键信息：根据问题中的关键词，像侦探一样回到文本相应区域去找。
  4. 第四步·仔细核对信息：特别注意数字、单位、时间、地点、限制条件等细节。
  5. 第五步·整合信息作答：答案可能不在一个地方，需要结合不同部分综合判断，或用自己的话归纳整理。
这一步最容易被跳过的是「第四步核对」。数字单位看错、年龄区间套错，是这类题失分的主因。

实用类文本编者归纳

书信、通知、新闻、启事这类文本为实际用途而写，读它们的目标很单一：拿到需要的信息，看清是谁写给谁、为了什么。读完能复述出时间、地点、人物、事项，就算过关。

方法：目的先行四步法
  1. 第一步·认清文体与格式：先看是书信、通知、新闻还是启事。称呼、落款、署名、日期的位置本身就是信息——通知的落款单位决定由谁来执行，新闻的导语往往就是全文最重要的那句话。
  2. 第二步·明确阅读目的：先读题目问什么，再带着问题去找。实用类文本不需要从头读到尾。
  3. 第三步·定位关键信息：抓「五要素」——时间、地点、人物（或对象）、事项、要求（或结果）；新闻再补上原因与经过。
  4. 第四步·核对细节：单位、数字、日期、范围、条件逐项核对，特别注意「不」「除……外」「仅限」这类限定词，看错一个字，答案就反了。
实用类文本常与图表、说明书混编出题，答法完全一致：先定目的，再找位置，就是「非连续性文本」那张卡里五步寻宝法在另一种文本上的复用。

议论文读法编者归纳

议论文以说理为目的，读它的顺序和记叙文正相反：记叙文跟着情节往下走，议论文要先把结论找出来，再回头看依据。把握住论点、论据、论证三要素，一篇文章的骨架就清楚了。

方法：三要素定位法
  1. 第一步·找论点：先看位置——标题、开头、中间、结尾；再抓标志词——「可见」「总之」「所以」「归根结底」这类总说词，以及反复出现的词语。论点必须是一个表肯定或否定的判断句，不是一个短语。
  2. 第二步·清论据：分清事实论据（史实、事例、统计数据）和道理论据（真理、名人名言、谚语、原理、定律），并判断它论证的是中心论点，还是哪一个分论点。
  3. 第三步·看论证：识别举例论证、引用论证、对比论证、比喻论证、道理论证，再看清结构是总分式、层进式、对照式还是并列式。
  4. 第四步·理思路：按「提出问题（引论）—分析问题（本论）—解决问题（结论）」划分层次，概括每层意思，再用「首先……接着……最后……」串成一段话。
论点是「要证明什么」，论据是「用什么证明」，论证是「怎么证明」。三个问题分清了，第三编的六个考点就各归其位：考点 01、02 管前两个问题，03、04、06 管第三个，05 管语言。

文言文读法编者归纳

文言文读不动，多半是卡在字词而不是文意。先借注释把字面打通，再谈人物形象与主旨。小学阶段的文言文篇幅短、故事性强，读懂了故事，就读懂了一大半。

方法：四步通读法
  1. 第一步·借注释粗读：先读标题和注释，了解出处、人物和背景，再连读一遍。能懂六七成就往下走，不要在某个字上卡住。
  2. 第二步·断句定节奏：主语和谓语之间、句首发语词之后、关联词之后要停顿；对话中的「曰」「云」后面要断开。读顺了，句意自然会出来。
  3. 第三步·字字落实翻译：直译为主、意译为辅，按「留（专有名词）—删（无义虚词）—换（单音变双音、通假换本体）—调（特殊句式调序）—补（补出省略）—贯（文从字顺）」六字处理。
  4. 第四步·回扣人物与主旨：从直接描写（语言、动作、神态）、侧面描写、作者的评价性语句、具体事件四个角度归纳人物性格，再归结到文章告诉我们的道理。
字词的坑主要四类：一词多义、古今异义、通假字、词类活用。遇到解释不通的字，先想是不是这四类之一，再查注释；翻译的得分点也落在这四类加特殊句式上。

古诗文读前策略

古诗文用极凝练的语言描绘意境深远的画面。要读懂它们，需要借助注释的「拐杖」、展开想象的「翅膀」，先理解字面意思，再体会深层情感。

方法：五步法
  1. 第一步·解题知背景：读标题和注释，了解作者、朝代和写作背景，从整体上把握作品主旨。
  2. 第二步·疏通文字意：借助注释或工具书，逐字逐句翻译成现代汉语，弄清字面意思。
  3. 第三步·想象诗中景：根据文字描述，在脑海中勾勒画面。这首诗描绘了怎样的景象？有哪些景物？
  4. 第四步·品味言中情：分析景物和意象（月亮常代表思乡，柳树常代表送别），思考作者想表达怎样的情感。
  5. 第五步·赏析精妙处：重点分析最具表现力的关键字词（诗眼），体会其精妙；或赏析对偶等修辞的表达效果。
五步法解决「读不懂」，考点 1–5 解决「怎么答」。读诗先走五步，答题再回考点。

  • ①以「我」的所见所闻所感为线索，「我」是贯穿全文的线索。
  • ②通过「我」的见闻感受，表现或烘托人物……的形象。
  • ③在「我」的身上寄托了作者……的情感（希望）。

问法 03叙事时人称变化有什么作用

  • ①表现形式：第一人称作为全文的基本视角，偶尔插入第二人称，构成两种不同人称的交叉。
  • ②作用：不同人称的出现丰富了文章的叙事手段，有助于作者思想感情的表达；营造了一种亲切的气氛，拉近了作者和读者的距离。

  • ②修辞角度：运用的修辞手法 → 修辞的作用 → 表达的情感。
  • ③词性角度：判断词性 → 表现出的作用（人物形象、品质等）。A. 动词、形容词：极富表现力，生动形象地写出了…… B. 副词：修饰（限制）了××一词，贴切形象地体现了……的特征，表达了……的情感。C. 拟声词：生动形象地描绘了……的情态美，流露……的情感。D. 叠词：音律和谐，富有节奏感，加深语意。
  • ④感情色彩角度：运用反语或褒贬反用，在特定语言环境中表达特殊感情。
答题模板①××词有……的意思，写出了……的情景，表达了……的思想感情。②××词写出了……（结合文章内容），表达了……的思想感情。③××词运用……手法，表现/揭示/突出了事物/人物的……特点，表达了……的思想感情。

问法 04××词语能否删去

  • ①从词语含义角度：注意词义的不同侧重点。
  • ②从词语感情色彩角度：褒义词不能用于贬义，贬义词不能用于褒义。
  • ③从词语生动形象角度。
答题模板①「可以」或「不可以」（一般情况不可以，特别是书上的原文）。②（结合句子分析效果）该词强调突出/限制/说明/修饰了……形象，恰如其分地表现了……特点。③如果删掉，则不能体现语言的准确/严密/生动/形象，或与事实不符，或太绝对等，所以不能删。

问法 05××词语能否改换成××

  • ①（一般情况）不能。
  • ②解释词义，比较两个词含义上的差别。
  • ③（动词）因为该词准确生动具体地写出了……／（形容词）因为该词生动形象地描写了……／（副词）因为该词准确地说明了……的情况（表程度、表限制、表时间、表范围等）。
  • ④换成××后，没有这种效果，所以不能换。

问法 06某两/三个词的顺序能否调换

  • ①（一般情况）不能。
  • ②因为与人们认识事物的规律（由浅入深、由表及里、由现象到本质）不一致；该词与上文的……是一一对应的关系；这些词为递进关系，环环相扣，所以不能调换。

12表现手法
口诀面点中心

面罩全文的结构手法：伏笔、铺垫、前后照应结构类

点落局部的手法：悬念、欲扬先抑、对比、衬托、烘托渲染局部类

中心所有手法的模板最后一步都归到“突出中心／主题”每个模板尾句

为什么是它判断手法先看它罩多大的“面”；答题不管用哪种，最后都落回“中心”两个字。

问法 01伏笔

  • 特点：①伏笔通常比较隐蔽。巧妙的伏笔，在没有看到「应笔」之前，貌似「闲笔」。②伏笔通常只是点到为止。
  • 作用：交代含蓄，使文章结构严密紧凑，情节发展合理。
  • 模板：××（句、段、物）表明……，为下文埋下伏笔，使文章前后照应，结构严谨。

问法 02铺垫

  • 特点：①铺垫对起陪衬作用的部分往往大肆渲染，以引起读者注意。②铺垫所使用的笔墨往往较多，可谓浓墨重彩。
  • 作用：突出主要人物、事件，增加情节张力，制造悬念，使情节具有合理性。
  • 模板：通过对……的描写，表现（渲染）了……，突出了……，为下文……做了铺垫。

问法 03前后照应

  • 特点：前面提到内容，后面有着落；后面讲的情节，前面有所交代。
  • 作用：使文章浑然一体，整体感强，突出主题。
  • 模板：……与……相互照应，为下文……情节做铺垫，使情节完整、结构严谨、中心突出。

问法 04托物言志

  • 特点：通过特定的、容易引起联想的具体形象，表达与之相似或相近特点的思想和感情。
  • 作用：表达含蓄、深刻；使抽象事物具体化，深奥的道理通俗化，感染力强。
  • 模板：抓住了……与……相似的特点，通过对……的准确刻画，含蓄地表明作者……的情感。

问法 05衬托（正衬 / 反衬）

  • 特点：以次要的人或事物衬托主要的人或事物，突出主要的人或事物的特点、性格、思想、感情等。用类似的事物作陪衬叫正衬，用反面的、有差别的事物作陪衬叫反衬。
  • 作用：突出主体，或渲染主体，使之形象鲜明，给人以深刻的感受，增强文章的表现力。
  • 模板：用……衬托……，使……形象更鲜明，增强了文章的表现力。

问法 06对比

  • 特点：把两个相反、相对的事物，或同一事物相反、相对的两个方面放在一起，用比较的方法加以描述或说明。分为横向对比和纵向对比两种形式。
  • 作用：突出被描写事物的本质特征，揭示其本质；加强文章的艺术效果和感染力；给读者以鲜明而深刻的印象；衬托、突出主体事物的特点，强调作者要表达的情感。
  • 模板：运用对比……巧妙地呈现在读者眼前，让读者很自然地从对比中感觉到……的变化，从而鲜明地表现或突出事物的特点，更好地表现文章的主题。

问法 07烘托渲染

  • 特点：用一事物暗示出另一事物，用衬托或夸张的艺术手法使事物形象鲜明突出。
  • 作用：表现环境，营造氛围，抒发情感，突出主题。
  • 模板：通过对人物或环境的描写，层层铺叙，营造意境，使描写的形象更加鲜明、突出。

问法 08欲扬先抑（欲抑先扬）

  • 特点：「扬」指褒扬、抬高。「抑」指向下压、贬低。作者想要褒扬（贬抑）某个人物或事物，却不从褒扬（贬抑）处落笔，而是从相反的贬抑（褒扬）处落笔。
  • 作用：①凸显变化的节奏美，使情节曲折动人。②使人物形象更加丰满，情感表达更加充沛。③形成鲜明的对比，给读者留下深刻的印象。④起卒章显志的作用。
  • 模板：作者的本意是……，而先……形成鲜明对比，……使情节更曲折，形象更丰满。

问法 09设置悬念

  • 特点：在文章的某部分设置疑问或矛盾冲突，以引起读者某种急切期待和热烈关心的心理。
  • 作用：使情节环环相扣；使文章情节曲折生动；激发读者阅读兴趣；达到震撼人心的效果。
  • 模板：先把……抛给读者而不说原因，层层设疑，激发读者的阅读兴趣。

问法 10以小见大

  • 特点：通过小事件和细节来揭示重大主题，反映深广内容。
  • 作用：突出表现中心，更有震撼力。
  • 模板：从人们所熟知的……入题，让人们从平常小事中领悟……的深刻道理，更具震撼力。

问法 11卒章显志

  • 特点：在文章结尾时，用一两句话点明中心、揭示主题。
  • 作用：结尾自然、有力，揭示文章主题。
  • 模板：文章用……结尾，自然、有力，增强了感染力，有「画龙点睛」的艺术效果。

13修辞手法

法先点手法名：运用比喻的修辞手法模板第一段

果写效果：生动形象、气势强、语气强烈模板第二段

点点对象：描绘了……的情景／特点模板第三段

问法 01比喻

  • 特点：包含本体和喻体，一般含有「像」「是」「如」「仿佛」「好像」等词语。
  • 作用：①可以把抽象的事物具体化、形象化，让读者产生联想。②用来阐述道理，使深奥的道理浅显化，让人易于理解、接受。③（记叙文中描写事物）突现事物的特征，把事物写得生动形象、具体可感，使人印象深刻。
  • 模板：运用比喻的修辞手法……生动形象地描绘了……的情景（特点），抒发（烘托）了人物……的心情（为下文的情节发展做铺垫）。

问法 02拟人

  • 特点：把物人格化，赋予事物以人的动作和情感。
  • 作用：赋予物以人的性格、思想、感情和动作，使具体的事物人格化，达到生动形象、表意丰富的效果。
  • 模板：运用拟人的修辞手法/把……拟人化，赋予……以人的思想、动作、情感，生动形象地描写了……的情景（或特点），抒发了……的情感。

问法 03排比

  • 特点：具有三个或三个以上结构和长度类似、意义相关或相同的句子。
  • 作用：句式整齐，条理清晰，节奏鲜明，气势强，便于抒情，表达效果好。
  • 模板：运用排比的修辞手法，抒发了……强烈感情，表现了……的特点，整齐优美，气势磅礴。

问法 04夸张

  • 特点：对事物的形象、特征、作用、程度等有意扩大、缩小或超前描述。
  • 作用：突出特征，引起联想效果，给人留下鲜明而深刻的印象；烘托气氛，增强感染力。
  • 模板：运用夸张的修辞手法，突出（强调）了……事物……的特征（特点），表达了……的情感。

问法 05对比

  • 特点：把事物的两个方面或将两个事物相对着记叙，常有「比」「好」「多」等表示对比的词。
  • 作用：通过对比，使事物的性质、状态、特征更鲜明突出。
  • 模板：运用对比的修辞手法，把……与……进行对比，突出……的特点。

问法 06反复

  • 特点：某个词语或句子重复出现。
  • 作用：①多次强调，给人留下深刻印象；②抒情强烈，富有感染力；③让文章的脉络更清晰。
  • 模板：运用反复的修辞手法，突出了……句子描写的内容，强烈地表达了……情感。

问法 07对偶

  • 特点：上下两句结构相同、字数相等、词性相对、意思相近或相反。
  • 作用：语言凝练，整齐匀称，音韵和谐，节奏感强。
  • 模板：①运用对偶的修辞手法，抒发了……的情感；②使文章句式整齐，音韵和谐，读起来朗朗上口。

问法 08设问

  • 特点：为突出所说的内容，把它用问话的形式表示出来，自问自答。
  • 作用：①自问自答，引人注意；②启发思考；③突出某些内容，使文章起波澜、有变化。
  • 模板：运用设问的修辞手法，提出问题，引人思考，强调（表达）了……的特点（的感情）。

问法 09反问

  • 特点：用疑问的形式来表达确定的意思，不需要回答。
  • 作用：①态度鲜明；②加强语气，抒情强烈。
  • 模板：运用反问的修辞手法，加强了语气，突出（强调）了……的特点，强烈地表达了……的情感。

问法 10反语

  • 特点：正话反说或反话正说，含有否定、讽刺以及嘲弄的意思。
  • 作用：比直白的表达更有力，语气更强烈，情感更充沛，给人的印象也更鲜明。
  • 模板：运用反语的修辞手法，显得幽默风趣，讽刺了……，流露……的感情。

问法 11引用

  • 特点：引用现成的话，如诗句、格言、成语等，以表达自己的思想感情。
  • 作用：既可使文章言简意赅，有助于说理抒情；又可增加文采，增强表现力。
  • 模板：运用引用的修辞手法，引经据典，含蓄典雅，增强了文章的生动性和形象性。

15表达方式

问法 01记叙

  • 定义：交代人物的经历、事件的发展变化过程以及场景、空间的转换。
  • 作用：①介绍事件发生、发展过程；②介绍人物的经历与事迹；③为议论抒情提供依据。

问法 02说明

  • 定义：简明扼要地把事物的形状、性质、特征、成因、关系、功用等解说清楚，把人物的经历、特点表达明白。
  • 作用：①详细、准确地介绍事物，突出事物……的特征；②把抽象的事物或道理说得清楚明白，让人易于理解和接受。

问法 03议论

  • 定义：对某个问题、事件进行分析、评论，表明自己的观点、立场、态度、看法和主张。记叙文中的议论往往起揭示记叙目的和意义的作用。
  • 作用：①增强文章表达效果；②明确文章主题，揭示蕴含的思想意义；③贯通文脉，紧凑篇章结构；④突出中心，揭示主旨。

问法 04抒情

  • 定义：在文章中抒发主观感受和思想感情。有直接抒情和间接抒情两种。
  • 作用：①以情动人，增强文章感染力，引起共鸣；②开拓意境，表现和深化主题思想；③渲染气氛，显示行文格调，贯通文章意脉。

问法 05描写 —— 人物描写

  • 定义：用生动的语言，把人物的状态、动作，景物的特征、环境的特点等具体地描绘出来。
  • 动作描写：对人物个性化行为、动作的描写。作用：表现鲜明的人物个性。
  • 神态描写：对人的面部神情的描写。作用：凸显人物个性，表现人物心理，使人物形象栩栩如生。
  • 外貌描写：描绘人物的身材、容貌、仪态等。作用：以「形」传「神」，揭示人物的思想品质、精神风貌。
  • 心理描写：对处在一定环境下的人物心理活动（内心感受、思想斗争等）的描写。作用：反映人物的内心世界，交代人物的思想感情基础和行动的内在依据。
  • 语言描写：描绘人物的独白、对话或谈话。作用：反映人物的心理活动，表现人物的思想感情，使人物形象丰满鲜活，可推动故事情节发展。
  • 模板：运用（动作、神态、外貌、心理、语言）描写，生动形象地写出了……的情形，表现了人物……的心理，刻画了……的人物形象。

问法 06描写 —— 环境描写

  • 自然环境：指对自然界的景物，如季节变化、风霜雨雪、山川湖海、森林原野等的描写。作用：①表现地域风光，提示时间、季节和环境特点；②渲染环境，营造气氛，奠定感情基调；③烘托人物心情（感情）；④衬托人物形象，表现人物性格；⑤为……做铺垫，推动情节发展；⑥突出、深化主题。
  • 社会环境：指对能反映社会、时代特征的建筑、场所、陈设等景物以及民俗、民风等的描写。作用：①交代人物的生存环境（时代背景），揭示人物的社会关系；②渲染环境气氛，衬托人物心情；③为人物性格描写做铺垫；④推动情节发展，深化作品主题。

问法 07描写 —— 正面描写（直接描写）

  • 特点：用生动形象的语言把人物或景物的状态直接具体地描绘出来。
  • 作用：直接描写人物特点（如性格、心理、情感等），给人直接、真实、具体的感受。

问法 08描写 —— 侧面描写（间接描写）

  • 特点：通过对其他人物、事物的描绘、渲染，烘托描写对象，使其鲜明突出。
  • 作用：①使人物或事件更加突出；②使主题更加深刻、含蓄。

问法 09描写 —— 细节描写

  • 特点：抓住生活中的细微而又具体的典型情节，加以生动细致的描绘。细节：指人物、景物、事件等表现对象的富有特色的细枝末节。
  • 作用：①烘托环境气氛；②刻画人物性格；③揭示主题思想；④推动情节发展。

问法 01辨识说明对象

  • 基础概念：①说明对象是指被文章说明的事物或事理。②事物说明文的说明对象是具体事物。③事理说明文的说明对象是某个抽象事理。

问法 01第×段有什么作用

  • ①开头段：总领下文；引出下面……内容的说明；点明/引出……（说明对象或特征）；用……手法，激发读者的阅读兴趣；增强文章的文学色彩。
  • ②中间段：承上启下（总结前文，引出下文）；承接上文……内容的说明；引起下文对……的说明；引起读者的注意和思考。
  • ③结尾段：总结全文；前后照应，使结构完整；总结说明对象的特征；提出问题，引发思考。

问法 02第×段与第×段能否调换顺序

  • ①（一般情况）不能。
  • ②概括各段的说明内容（第×段运用了……的说明顺序，介绍了……，或第×段讲的是……）。
  • ③段落间属于时间/空间/逻辑顺序；文章为总分式/递进式/承接式的结构关系；与前文……内容是照应关系，符合人们认识客观事物的规律。
  • ④如果调换，则不符合人们认识客观事物的规律，所以不能调换。

问法 03第×段能否删除

  • ①（一般情况）不能。
  • ②概括该段说明内容（第×段运用了……的说明顺序，介绍了……）。
  • ③对……内容起补充说明的作用；说明了事物……特点；结构上起……作用；说明顺序属于……顺序。
  • ④如果删去，就没有这种作用/效果，所以不能删去。

问法 04所给材料放在哪一段合适

  • ①结构角度：材料说明……内容。放在×段，可以在结构上起到……作用。
  • ②内容角度：材料说明……内容，与×段说明的……内容一致。
  • ③说明方法角度：材料说明了……内容，放在第×段，可以作为事例具体有力地说明……特点（或与某段说明内容一致）。
  • ④衔接角度：材料说明了……内容，与上下文衔接紧密（或与文段中某内容相关联）。

问法 05在某处补写一个句子

  • ①分析上下文。看上下文写了什么内容。
  • ②明确位置及类型（承上启下的过渡句、总结上文句、领起下文句）。
  • ③补写句子。与上下文衔接紧密，语言简洁。总结性句子要注意前后文说明的事物特点和内容。

05说明顺序

问法 01说明顺序分类

  • ①时间顺序：按事物发展过程来说明。用途：说明生产技术、产品制作、工作方法、历史发展、动植物生长、人物成长等。
  • ②空间顺序：按事物空间结构的顺序来说明。用途：介绍事物的形状及构造、建筑物的外形及构造等。
  • ③逻辑顺序：按事物、事理的内在逻辑关系来说明。用途：说明事理内部联系、事物认知规律等。

问法 02辨别说明顺序

  • ①抓关键词。（时间顺序：表示时间的数字、年代等。空间顺序：表示方位、立足点、行踪变化的上下、远近、内外、东西南北等。逻辑顺序：表示因果、事理顺序的首先、其次、然后、最后等。）

01议论文的论点

问法 01找中心论点

  • 基本概念：①论题：作者要讨论的问题。②论点：作者对所讨论问题所持的见解或主张（明确表明作者态度或观点，表肯定或否定的判断句）。③中心论点：作者在文中提出的核心观点。议论文一般都有一个中心论点。④分论点：各部分用以补充和支持中心论点的分支论点。
  • 答题策略：①看位置（标题 → 开头 → 中间 → 结尾）。②抓关键词（「可见」「总之」「所以」「归根结底」等总说词；过渡词；反复使用的词）。③提取分论点。④分析论据。

问法 02概括中心论点

  • ①按位置寻找，摘抄或改编句子为表判断的陈述句，根据分论点概括中心论点。
  • ②找关键词，连词成句。

问法 03补写分论点

  • ①紧扣中心论点或论题，提炼关键词概括。
  • ②和文中分论点句式一致。

问法 04文章是如何提出中心论点的

  • ①开门见山。②由社会现象提出问题。③根据亲身经历。④引用故事或名言警句。

问法 05议论文标题有什么作用

  • ①内容上：点明论点或论题，概括议论的主要内容。
  • ②手法上：A. 运用……（比喻、拟人）的修辞手法，生动形象地写出了……观点或内容。B. 运用反问/疑问句式，启发读者思考。C. 用语新颖别致/亲切生动。D. 引用诗词名句，富有文采。
  • ③效果上：激发读者阅读兴趣。

02议论文的论据

问法 01分析××（句/段）论据的作用

  • 基本概念：①事实论据：包括史实、事例、统计数据等。②道理论据：包括已被证实的真理、名人名言、谚语、原理、定律、公式等。
答题模板列举……事例 / 引用……名言，作为事实/道理论据，论证……观点，具有增强论证说服力的作用。

问法 02概括事实论据

  • 按「谁 + 做了什么 + 结果如何」提取，且须含有体现论点的关键词。
答题模板什么人 + 做了什么事 + 结果如何（要体现论点的关键词）。

问法 03某个事例或道理是否适合作论据

  • 这是一个事实论据/道理论据，论述……观点，而文章的中心论点是……，论据有力论证/不能论证中心论点，所以能/不能作论据。

问法 04为第×段补充论据

  • ①明确该段论点。
  • ②分清补充的是事实论据还是道理论据。
  • ③补充事实论据，应是典型人物的典型事例，要有能体现观点的关键词；补道理论据，应交代清楚名言诗句的作者、国别或朝代。
答题模板①事实论据：人物 + 事件 + 结果。②道理论据：时代（国籍）+ 作者 + 言论。

问法 05论据放在文中哪一处合适

  • ①文章的中心论点……，其中又有……等分论点。
  • ②分析材料可知，材料所表达的观点是……。
  • ③该论据论证了……这一分论点，所以应放在××处。

03论证结构

问法 01论证结构

  • 一般结构：提出问题（引论）— 分析问题（本论）— 解决问题（结论）。
  • 总分式（总分、分总、总分总）：总分式里分述各项一般都是并列的。
  • 层进式：由浅入深。段与段之间常常有一些递进式的标志，如「不仅如此」「而且」「甚至」等。
  • 对照式：在论证过程中，把两种事物或意思加以对比，或者用一种事物或意思来比照另一种事物或意思，就是对比式。
  • 并列式：行文在几个并列的层次或者段落之前常常标有「第一」「第二」，「首先」「其次」或「……上看」「……上分析」等形式。

问法 02××句（段）有什么作用

  • ①开头段：A. 开门见山，提出……中心论点。B. ……事例/引用名言/引用名人趣事，提出……中心论点（引出……论题，为下文做铺垫）。C. 充当事实/道理论据，起到证明中心论点的作用。D. 激发读者的兴趣。E. 摆出要批驳的论点，为下文的批驳树立靶子。
  • ②中间段：承上启下，承接上文阐述的……内容，引出下文关于……的论述。
  • ③结尾段：总结全文，提出……中心论点；照应开头或题目，强调……中心论点；指出议论或意义的作用，发出……的号召或希望人们……；补充论证……使论证严密。

问法 03×句（段）能否调换顺序

  • ①（一般情况）不能。
  • ②概括各句（段）内容。
  • ③这些句（段）间具有前后照应关系/递进关系/时间顺序，符合人们认识客观事物的规律。
  • ④如果调换，则不符合逻辑，所以不能调换。

问法 04第×段能否删去

  • ①（一般情况）不能。
  • ②概括该段论证内容（第×段运用……的论证方法，论证了……）。
  • ③对……（中心论点）起补充论证的作用，是一个重要的分论点。
  • ④如果删去，就不能有力地论证中心论点，所以不能删去。

  • 特点：用事例证明论点。标志：如、比如、例如、譬如等。
  • 作用：举……事例证明了……分论点/中心论点，从而使论证更加真实可信，更有说服力。

问法 02引用论证

  • 作用：运用引用论证，通过引用……证明了……的观点，使论证更具权威性，更有说服力。

问法 03对比论证

  • 特点：用正反两方面的事实和道理进行对比，从而证明了……。
  • 作用：运用对比论证，将……和……加以比较，突出强调了……的观点。

问法 04比喻论证

  • 特点：通过生动形象的比喻来证明论点的方法。
  • 作用：运用比喻论证，……证明了……的观点，把抽象深奥的道理阐述得生动形象、浅显易懂。

  • ②××词的意思……在程度/范围/数量/时间/语气上起限制作用。

  • ④××词准确论证了……（内容），体现了议论文语言的准确性、严密性，所以不能删。

  • ②如「……」找出具体语句，句中的……（词语）准确地/概括地说明了……内容；或运用……的修辞手法，生动地刻画了（阐述了）……的内容/观点。

01理解重点词语

问法 01文言实词——一词多义

  • 一词多义：本义、引申义、比喻义、假借义。

问法 02文言实词——古今异义

  • ①词义扩大。例：江、河、池、中国、山东等。
  • ②词义缩小。
  • ③词义转移。例：涕涸、烈士、穷、走、去、狱、行李、颜色等。
  • ④词义强化。例：恨、诛等。
  • ⑤词义弱化。例：饿、很、怨、羞等。
  • ⑥感情色彩。褒义变贬义（爪牙、可怜、复辟、明哲保身等）；贬义变褒义（乖等）；中性变褒义或贬义（牺牲、下流、卑鄙、谤等）。
  • ⑦偏义复词。相近或相关（巷陌、国家、崩殂、父兄、耳目等）；相对或相反（存亡、远近、生死、浅深、出入等）。
  • ⑧单音偶合。例：然后、然而、其实、从而、中间等。
  • ⑨说法改变。例：目、日、前、敬等。

问法 03文言实词——通假字

  • ①音同形似。如：「日侍坐备问」，「坐」同「座」，意思是「座位」。
  • ②音近形似。如：「属予作文以记之」，「属」同「嘱」，意思是「嘱托」。
  • ③音同形异。如：「左手倚一衡木」，「衡」同「横」，意思是「横放的」。
  • ④音近形异。如：「河曲智叟亡以应」，「亡」同「无」，意思是「没有」。

问法 04文言实词——词类活用

  • ①名词：A. 作动词：恐前后受其敌。（《狼》）B. 作形容词：益于众矣。（《爱莲说》）C. 作状语：其一犬坐于前。（《狼》）
  • ②动词：A. 作名词：止增笑耳。（《狼》）B. 使动用法：饿其体肤。（《生于忧患，死于安乐》）C. 作副词：寻病终。（《桃花源记》）
  • ③形容词：A. 作名词：此皆良实。（《出师表》）B. 作动词：尔安敢轻吾射？（《卖油翁》）C. 使动用法：无丝竹之乱耳。（《陋室铭》）D. 意动用法（形容词 + 宾语）：渔人甚异之。（《桃花源记》）

问法 05文言虚词——副词

  • ①时间副词（业、已、尝、适、将、俄而、未几等）；②否定副词（不、弗、莫、毋、勿、无、靡、否等）；③范围副词（俱、咸、悉、举、独、仅、凡等）；④程度副词（少、极、甚、略、颇、太、至、愈等）；⑤情态副词（遽、卒、间、暂、毕、旋、亟、屡、累等）；⑥语气副词（定、信、果、盖、竟、可、岂、宁等）；⑦谦敬副词（谨、幸、惠、辱、蒙、窃、请、敬等）；⑧指代副词（相、见等）。

问法 06文言虚词——连词

  • ①表并列（与、及、且、而、暨等）；②表转折（而、然、则、然则、可、却、但等）；③表递进（而、且、并且等）；④表因果（以、为、因、由、缘、是故、是以、所以等）；⑤表承接（而、则、因、乃、遂、于是等）；⑥表假设（向、向使、使、即、若、必、纵、纵使、假如等）。

问法 07文言虚词——助词

  • ①音节助词（有、其、然、焉、如、乎等）；②句首助词（夫、盖、嗟、惟等）；③句中助词（夫、盖、也、与等）；④句末助词（也、矣、焉、耳、已、乎、耶、兮、哉等）。

问法 08文言虚词——代词

  • ①人称代词：A. 第一人称（我、余、予、吾、愚、己等）；B. 第二人称（汝、尔、乃、子、君、卿等）；C. 第三人称（之、其、彼、伊、焉等）；D. 复数（属、辈、类、族、徒等）。
  • ②指示代词：A. 近指（是、此、斯、兹、之、然等）；B. 远指（彼、夫、其等）；C. 无定代词（或、莫、无等）；D. 旁指代词（它、他等）；E. 辅助性代词（所、者等）。
  • ③疑问代词：A. 代人（谁、孰等）；B. 代事物（何、胡、奚、曷、盍等）；C. 表处所（安、恶、焉等）。

问法 09文言虚词——其他

  • ①叹词（唉、嗟、呜呼、嗟乎等）；②介词（以、因、于、为、同、乎、自、从、缘等）；③拟声词（泠泠、嘤嘤、呼呼、唧唧、呦呦、萧萧等）。

02翻译重点语句

问法 01翻译标准

  • ①信（准确）：忠于原文，不歪曲，不遗漏，不增加。
  • ②达（通顺）：明白晓畅，符合现代汉语表达习惯，无语病。
  • ③雅（文采）：语言规范、得体、生动、优美。

问法 02翻译原则

  • 直译为主，意译为辅，字字落实，文从字顺。

问法 03翻译方法

  • ①留：基本词汇和专有名词保留。包括：古今意义相同词；朝代、年号、人名、地名、官职、度量衡单位等专有词。
  • ②删：无意义或没必要译出的衬词、虚词、助词等删去。
  • ③换：单音词换为双音词；换活用后的词；通假换本体。
  • ④调：特殊句式按现代汉语要求调整为正常句式。
  • ⑤补：补出省略内容。
  • ⑥贯：结合语境，文从字顺。

问法 04翻译得分点

  • ①重点实词（一词多义、词类活用、古今异义、通假字）。
  • ②关键虚词（有实义或在句子结构中起作用）。
  • ③特殊句式（省略句、被动句、判断句、倒装句、修辞句、固定句式）。

03文言文断句

问法 01借助语法结构断句

  • ①主语、谓语、宾语之间要断开。（例：予 / 尝求 / 古仁人之心）
  • ②谓语中心语与后置的介宾短语之间要断开。（例：不求闻达 / 于诸侯）
  • ③并列短语之间要断开。（例：惟长堤一痕 / 湖心亭一点 / 与余舟一芥 / 舟中人两三粒而已）
  • ④动词和补语之间要断开。（例：王之弊 / 甚矣）
  • ⑤后置的介宾短语前要断开。（例：三顾臣 / 于草庐之中）
  • ⑥提前的状语，其后和主语之间要断开。（例：今 / 天下三分）
  • ⑦后置的状语前要断开。（例：天下苦秦 / 久矣）
  • ⑧修饰语和中心词之间不能分开。（例：潭中鱼 / 可百许头）
  • ⑨句首状语后要停顿。（例：对于 / 骂父，相委 / 而去）

问法 02实词与虚词提示断句

  • ★句首发语词后要停顿（优先停顿）。句首发语词指放在句子的开头、只充当语气助词的虚词，如「至于」「夫」「若夫」「盖」「且」等。（例：若夫 / 日出而林霏开。夫 / 学须静也。盖 / 以诱敌）
  • ★句首关联词后要停顿（优先停顿）。句首出现表假设、转折等的关联词，如「若」「而」「然则」等，或表总结性的词语，如「故」「是故」等要停顿。（例：然则 / 何时而乐耶？故 / 自号曰醉翁也）
  • ★「古今二一」：在古代是两个单音词，而在现代汉语中是一个复音词的，要分开（优先停顿）。（例：可 / 以 / 为师矣）
  • ★在表示转折意思的句子中，按照「而前则前」的原则划分朗读节奏。（例：人不知 / 而不愠。学而不思 / 则罔。险躁 / 则不能治性）
  • ★有省略成分的地方要停顿。（例：投以骨。过中 / 不至）
  • ★「也」「乎」等语气助词后要停顿。（例：余闻之也 / 久。宜乎 / 众矣）

问法 03其他断句规则

  • ★根据文句内在的逻辑确定是否停顿。（例：元方 / 入门 / 不顾。居庙堂之高 / 则忧其民。其一 / 犬坐于前）
  • ★古人的姓、名、字、封号、谥号、谦称、自称、别称、尊称、官名、地名、国名等的后面要停顿。（例：左将军 / 王凝之 / 妻也）
  • ★读骈句，节奏必须整齐划一，凡四字句皆两字一顿。（例：树木 / 丛生，百草 / 丰茂。日月 / 之行，若出 / 其中；星汉 / 灿烂，若出 / 其里）
  • ★连读不停顿：作状语名词与中心词间（例：……之适于渤海之尾）；偏正短语间（例：前人之述 / 备矣）；介宾短语间（例：有朋 / 自远方来）；作为一个语义单位（例：未能 / 远谋）；「而」在句中表并列、修饰、承接关系等〔例：敏而好学（表并列）/ 面山而居（表修饰）/ 收而攻蕲（表承接）〕。

04分析文中人物形象

问法 01常考题型

  • ①分析概括××人物性格。②简要分析××是一个什么样的人。

问法 02答题角度

  • ①通过直接描写分析人物：通过对人物的肖像、行动、语言、心理等分析，揭示人物思想品质和性格特点。
  • ②通过侧面描写分析人物：通过他人的言行来认识主要人物形象。
  • ③从评价性语句分析人物：通过作者对人物的评价语句，往往能概括出人物的性格品质。
  • ④通过分析事件分析人物：通过人物在具体事件中的表现，可以分析出人物的性格品质。
  • ⑤口诀：标题开头须关注，具体事件显性格，语言动作析特点，侧面描写起烘托。

05文言句式

问法 01判断句

  • 「者」「也」表判断。
  • 「本」「为」「乃」「即」「是」等副词表肯定判断。
  • 「非」「莫」「无」表否定判断。
  • 语义上主谓直接判断。

问法 02被动句

  • 「见」「见……于」等表被动。
  • 「于」表被动。（例：闻之于宋君）
  • 「为」「为……所……」等表被动。（例：吴广素爱人，士卒多为用者）
  • 没有被动词，意思上隐含被动。

问法 03省略句

  • 省略主语。（例：乃大惊，问所从来）
  • 省略谓语或动词。（例：其家甚智其子而疑邻人之父）
  • 省略宾语。（例：夺而杀尉）
  • 省略介词。（例：林尽（于）水源）
  • 省略量词。（例：与余舟一芥）

问法 04倒装句——主谓倒装

  • 强调谓语，把谓语提前。（例：甚矣，汝之不惠）

问法 05倒装句——宾语前置

  • 疑问句中，疑问代词作宾语。
  • 否定句中，代词作宾语。
  • 「之」「是」将宾语提到动词前。
  • 介宾短语、方位或时间词作宾语。

问法 06倒装句——定语后置

  • 中心词 + 之 + 后置定语。（例：居庙堂之高则忧其民）
  • 中心词 + 之 + 后置定语 + 者。（例：马之千里者）
  • 中心词 + 数量词。（例：尝贻余核舟一）

问法 07倒装句——状语后置

  • 介词「于」组成的介宾短语后置。
  • 介词「以」组成的介宾短语后置。

问法 08固定句式

  • 表陈述：无以、无从、有以、有所、无所等。
  • 表感叹：何其、直（惟）……耳、亦……哉等。
  • 表疑问：奈何、何如、何以、何所、奈……何、孰与……等。
  • 表反问：何……哉（也、为、之有）、岂……哉（乎、耶）等。
  • 表设问：何者、何则等。
  • 表选择：与……孰若、其……其……也等。
  • 表揣度：无乃……乎、得无……乎、庶几……欤等。
